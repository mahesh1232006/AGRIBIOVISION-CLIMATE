# AgriBioVision Climate

Climate-smart agricultural decision-support application.

## Modules

- Dashboard
- Climate & Water
- Crop Health
- Integrated Risk
- Recommendations
- Impact Indicators
- Scientific Evidence
- Data Downloads

## Scientific scope

The crop-health model is a PlantVillage benchmark baseline.

Field validation is not established.
Global validation is not established.
The system does not claim causal climate-to-disease relationships.
Impact indicators are normalized screening indicators.

## Run locally

pip install -r requirements.txt

streamlit run app.py
